# Xiaohongshu Post 03 — Review Style

## CES Strategy (brief)

Review content drives **high-intent conversion** and strong comment volume (people argue about ratings). Tactics applied here:

- **Title:** ≤20 characters, keyword ("测评") inside the first 13 characters; brand names for search.
- **Body:** 300–600 characters, rating scales (7/10, 8/10), pros and cons, "适合人群/不适合" sections — the format XHS review readers save and share.
- **Objectivity:** honest cons included (校准麻烦, 设置门槛) — increases credibility and comment engagement.
- **Golden 2 hours:** Tues/Thurs/Sat 19:00–20:00.
- **Tags:** 5–8 hashtags including mandatory #AIContent / #AI生成内容.
- **CTA:** Opinion question at the end ("你会为了隐私放弃云端便利吗？") — triggers the comment signal, the second-heaviest CES weight.
